# Bundled fonts (DM Sans)

The app ships with placeholder TTF files so typography works offline on PAX terminals.

For production branding, replace these with official **DM Sans** files from [Google Fonts](https://fonts.google.com/specimen/DM+Sans):

- `DMSans-Regular.ttf` (400)
- `DMSans-Medium.ttf` (500)
- `DMSans-SemiBold.ttf` (600)
- `DMSans-Bold.ttf` (700)

Keep the same filenames so `pubspec.yaml` does not need changes.
